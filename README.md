# 随手账 · 使用说明

一个简单的个人记账工具：打开就记，3 秒一笔。所有数据只存在你自己的浏览器里，不上传任何服务器。

---

## 一、怎么打开

### 方式 1：双击直接用（最简单）

直接双击文件夹里的 **`index.html`**，用浏览器（推荐 Chrome / Edge）打开即可开始记账。

> 数据保存在当前浏览器的本地存储里。换浏览器、换电脑、无痕模式，数据互不相通。

### 方式 2：局域网访问（手机也能用）

如果想在手机上记，让电脑和手机连同一个 Wi-Fi，然后在电脑上进项目文件夹执行：

```bash
# 任选一种（需要电脑装有 Python 或 Node）
python -m http.server 8080
# 或
npx serve -l 8080
```

然后手机浏览器输入 `http://<电脑的局域网IP>:8080`，例如 `http://192.168.1.5:8080`。

> 查电脑 IP：Windows 运行 `ipconfig` 看「IPv4 地址」；Mac 在「系统设置 → Wi-Fi → 详细信息」里看。

### 方式 3：线上访问（已部署，推荐手机用）

随手账已经部署到 **GitHub Pages**，有固定 https 地址，**手机、电脑、平板任意设备打开即用，不用记 IP、不用备案**：

```
https://shanghaining489-sketch.github.io/suishouzhang/
```

- 手机浏览器打开这个网址 → 添加到主屏幕，就成了桌面 App（详见第三节）
- 数据仍然只存在你设备本地，代码托管在 GitHub 不等于你的账目上传了

## 二、数据放在哪 · 怎么备份（重要）

随手账**没有账号、没有云端**，数据全部存在浏览器本地。这意味着：

- ✅ 隐私绝对安全，除了你没人看得到
- ⚠️ **浏览器数据一旦被清理（如用清理软件扫掉「浏览器缓存」），数据就找不回来**

**所以：每周去「我的 → 备份与恢复」导出一个 JSON 文件，存到网盘或 U盘里，养成习惯。**

### 备份操作

1. 底部 tab「我的」→「备份与恢复」
2. 点蓝色按钮「导出备份文件」
3. 得到一个 `随手账备份-YYYY-MM-DD.json`，保存好

### 恢复操作

1. 同样进入「我的 → 备份与恢复」
2. 点「选择备份文件」，选之前导出的 JSON
3. 确认后数据恢复（恢复前当前数据会自动留一个退路，可在「关于」页回退）

### 换手机 / 换电脑迁移

旧设备导出 JSON → 新设备打开随手账 → 导入该 JSON，一分钟搞定。

## 三、装成 App（PWA）

随手账支持「添加到主屏」，装上后和原生 App 一样全屏打开，**离线也能记**：

- **手机**：用浏览器打开后，Chrome 点「添加到主屏幕」/ Safari 点「分享 → 添加到主屏幕」
- **电脑**：Chrome / Edge 地址栏右侧会出现「安装」图标，点一下即可

> 注意：`file://` 双击打开时安装按钮可能不出现，用上面的局域网方式打开即可安装。

## 五、常见问题 FAQ

**Q：数据会不会丢？**
只要不清理浏览器数据就不会。但浏览器清理是防不胜防的（很多「清理加速」类软件会顺手清掉），所以务必定期导出备份。

**Q：为什么收入和支出的颜色是「红涨绿跌」？**
沿用了国内炒股/资金流向的习惯：收入红色、支出绿色，一眼分清进出。累计看几天就习惯了。

**Q：金额是整数「分」存的吗？**
是。内部全部按「分」存储和计算，不碰浮点数，不会出现 `0.1+0.2=0.30000000004` 这种错误。

**Q：想清空演示数据重新开始？**
「我的 → 关于」，连点版本号 5 次，可以管理（生成 / 清除）演示数据。

**Q：定期账设了每月 1 日，为什么有时显示「待生成」？**
到期后需要打开 App 才会检测到并提醒你一键生成（不会不打招呼自动记账）。点首页黄色横幅上的「全部生成」即可。

**Q：换了浏览器数据没了？**
数据不跨浏览器。用备份 JSON 在新浏览器里恢复即可。

## 七、部署到 GitHub Pages（上线方法 · 当前在用）

把随手账变成一个固定 https 网址，手机「添加到主屏幕」就能当 App 用。**选 GitHub Pages 的原因：免备案、不会被强制下载**——国内云（阿里 OSS / 腾讯 COS）对未备案的桶会返回 `Content-Disposition: attachment`，浏览器一律变成「下载文件」而非渲染网页，所以最终走 GitHub Pages。纯前端上传、无后端。

### 前提（GitHub 一次性操作）

1. 注册 GitHub 账号（当前部署用的账号 `shanghaining489-sketch`）
2. 生成一个有 `repo` 权限的 Personal Access Token（设置 → Developer settings → Personal access tokens → 勾 `repo`）—— **Token 只用来部署，部署完建议立刻撤销，见文末安全提示**
3. 仓库名 `suishouzhang` 设为 **Public**（GitHub Pages 对公开仓库免费）

### 一键上传

项目里已配好 `_deploy/` 暂存目录 + git 提交脚本。把代码 push 到 `https://<token>@github.com/shanghaining489-sketch/suishouzhang.git` 的 `main` 分支，再开 Pages 即可，命令示例：

```bash
cd _deploy
git init
git add -A
git commit -m "deploy 随手账"
git push https://<TOKEN>@github.com/shanghaining489-sketch/suishouzhang.git main
```

推送成功后，在仓库 **Settings → Pages → Source 选 `main` 分支 / root** 开启（或用 API `POST /repos/{owner}/{repo}/pages`）。约 1 分钟构建完成，访问：

```
https://shanghaining489-sketch.github.io/suishouzhang/
```

> 已验证：线上 26 个文件全部 200，无任何 `content-disposition` 强制下载头，iPhone Safari 可正常渲染并「添加到主屏幕」。

### ⚠️ 安全提示（重要）

本项目的国内云 AccessKey、GitHub Token 曾在聊天中明文出现过。它们已失去私密性，**强烈建议立即去对应后台撤销 / 轮换**：
- GitHub：Settings → Developer settings → PAT 列表撤销该 token，重新生成再用
- 阿里云：RAM 访问控制 → 删除当时创建的 AccessKey
- 腾讯云：访问管理 → 删除当时创建的 SecretId/SecretKey

### 关于「自动同步微信/支付宝」

微信支付、支付宝**没有给个人开放消费记录 API**，iPhone 网页 App 也读不到另一个 App 的数据，所以「买完自动进账」无法实现。1.2 的做法是：**截图 → 传到 AI 记账页 → AI 自动识别成多笔账单 → 批量保存**，比自动同步只多「截一张图」的动作，但省掉 90% 手输。后续也可加「微信/支付宝导出 Excel → 一键解析导入」。

### AI 记账怎么用（图片/截图识别）

图片识别依赖一个**视觉大模型**接口（纯前端直连，不经过任何中间服务器）：

1. 打开「AI 智能记账」页（首页蓝色卡片 / 我的 → AI 智能记账）
2. 点右上角 **⚙️** 填设置：
   - **服务商**选「通义千问视觉」或「硅基流动」（都已验证浏览器可直接调用）
   - 粘贴你的 **API Key**（在对应平台免费领取，如阿里云百炼 dashscope）
   - 模型和接口地址按默认值即可
3. 返回，点 **📷** 选一张微信/支付宝/银行账单截图 → 自动识别多笔 → 逐条可改 → 点「保存全部 N 条」
4. 想用语音：点 **🎤** 唤起键盘语音，说「午饭12块」即本地识别入账（免 Key）

> 密钥只存在你手机本地的 `localStorage`，截图仅发给所选 AI 用于识别，不会上传到随手账的任何服务器（随手账本身也没有服务器）。不填 Key 也能用语音记账。
